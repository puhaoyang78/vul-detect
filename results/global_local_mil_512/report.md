# Global–Local Dual-Stream MIL

三组使用同一正式模型、数据读取、优化器与评价入口；训练均从同一预训练 UniXcoder 初始化。
官方 paired Train 8,708 个函数，Valid 1,124 个函数；Seed123456、Batch8、512 Token、16 Epoch、17,424 步。
按完整 Valid P-C 四位小数选模，同分保留较早 Epoch；固定 probability > 0.5。历史权重不覆盖。

全局分支保留原 Context + Diff。局部分支为独立 Linear(768,2)，两个通道分别记作安全/漏洞证据；复用同一次编码的物理行均值。
Mean 对有效行等权平均；LSE 使用 logsumexp(scores)-log(N)，温度固定 1。共同的 log(N) 在类别差值中抵消，保留它以便比较类别分数。
最终 logit = global_logit + c*(local_class[1]-local_class[0])，c 无约束且零初始化。随机局部头在 CPU fork_rng 内初始化；新增 1,539 个参数。
仅使用最终函数 BCE + 0.1 原 Diff 区域损失。没有新区域标签、额外辅助任务或编码；推理只输入单函数。
两个局部通道是包级潜在证据，不是经过校准的行漏洞概率；c 的符号也应结合解释。

## 解释与结论

本轮失败。LSE 虽比 Mean 的 Valid P-C 高 1.07 pp，但比匹配 Context + Diff 低 2.31 pp，AUC/MCC 也分别降低 0.01561/0.03126；Test P-C 为 10.11%，低于基线的 12.41%。三组都完成了全部 16 Epoch，选中 Epoch 分别为 15、5、12，Mean 的较早 checkpoint 不代表提前结束训练。没有触发第二种子的扩展条件，没有追加变体或参数搜索。

最直接的证据是：Mean 和 LSE 在完整 Train/Valid 上，去掉局部残差均未改变任何一个函数类别，也没有新增或挽回正确配对。局部头存在梯度和参数更新，但所选融合系数仅为 -8.83e-5、2.46e-4，Valid 平均绝对 logit 残差为 4.84e-6、2.22e-5。因此，相比单独重新训练基线的配对得失，不能解释为推理时两分支的有效互补。

LSE 确实改变了实例分数的聚合：在所选 LSE 头的同一组行分数上，实际 LSE 类别 margin 与行均值 margin 的平均差为 0.05155，经过所学系数后约为 1.27e-5。这是分数统计分解，没有评测或选择新的推理方案。当前问题不是聚合公式未生效，而是局部残差没有形成可改变检测决策的量级。

LSE 修复侧 FPR 从基线的 52.49% 升至 62.63%，但同一 LSE 权重的 global-only 与融合预测完全相同；局部残差直接新增/消除的修复侧误报均为 0。Mean 的 FPR 降低也伴随 Recall 从 65.84% 降至 34.88%，且 global-only 已表现出同样的决策。这些变化由各自所选模型的全局读出体现，不能据此宣称局部安全通道改善了安全上下文识别。

纯新增修复上的 Valid P-C 为 baseline 22.70%、Mean 20.86%、LSE 20.25%；可见差异配对分别为 24.62%、19.85%、21.36%。改善并未隐藏在这两个重点子集中。164 对相同可见输入的 P-C 在三组中均为 0，新增读出不能恢复 512 Token 外缺失的修复差异。

## 验证及保留决定

105 项不同的相关单元测试通过，真实 RTX 4090 smoke 通过：原参数/RNG 不变、初始输出逐位一致、稳定 LSE/有效行屏蔽、跨行 Token 质量守恒、两步梯度与参数更新、磁盘恢复及单函数推理均已检查。首步局部头梯度为 0、融合参数梯度非零；融合参数更新后局部头获得非零梯度，未使用伪梯度。三组所选 checkpoint 的完整 Valid 批量预测恢复一致，Train/Valid 首函数与单函数推理检查全部通过 2e-6 容差。Test 的 1,128 个官方成员、硬标签和固定选模 Epoch 已核对，并从保存预测重算指标。

本轮新匹配基线的 P-C 为 98/562=17.44%，历史 Context + Diff 为 100/562=17.79%；成员、配置、参数量、输入覆盖和末态 CPU/活动 CUDA RNG 均一致，见 historical_baseline_check.json。相同随机流不能保证整个 GPU 训练逐位复现。本轮始终使用新训练的匹配基线，没有改换对照值。

保留 `--local-mil mean/lse` 及结果用于复现消融，默认仍为原 Context + Diff。当前结果不支持把双分支 MIL 作为主要方法或性能贡献。
