# 有效物理行等权区域损失：固定 Train/Valid 实验

历史 Context + Diff 使用 K=5、Token 数加权区域均值；新实验按要求同时改为 K=10、行等权区域均值。函数 MIL 仍按 n_i*r_i 聚合，BCE、0.1 区域损失、数据及训练协议不变。此次组合对比不能单独归因于行等权。

完整 Valid 的漏洞侧 TP 净变化 -85，修复侧 FP 净变化 -69。Recall 变化 -15.12 个百分点，修复侧 FPR 变化 -12.28 个百分点；AUC 变化 -0.0111，MCC 变化 -0.0306。

train: 用同一行等权口径复算的区域 margin 为 0.0333 → 0.0181；短修改行 per-token enrichment 均值 1.706 → 2.099，中位数 1.907 → 2.054。

valid: 用同一行等权口径复算的区域 margin 为 0.4235 → 0.4380；短修改行 per-token enrichment 均值 1.133 → 0.939，中位数 0.623 → 0.398。

≤4 Token 子集 P-C 的正确对数为 44 → 50，但 AUC 为 0.5945 → 0.5855，MCC 为 0.1637 → 0.1637。该子集结果需与完整 Valid 指标共同解释。

train: 区域损失有效函数 5180；仅一条可见修改行 1879；含短修改行 2041，其中多修改行 1899。

valid: 区域损失有效函数 658；仅一条可见修改行 217；含短修改行 232，其中多修改行 222。

单条修改行时，正区域均值不会因 Token/行等权而改变；变化只能来自背景均值及 K。多修改行时，行等权才直接提高短行相对长行的正区域梯度份额。原始倍率受 K 影响，故同时报告函数内 per-token enrichment。

Train 中按原顺序最先满足“漏洞侧、多条可见修改行、含 ≤4 Token 修改行”的五个函数为 sample 13、19、57、73、91。人工查看发现短行包括括号/else、函数签名片段、break/p++、变量声明和注释结束符；≤4 仅是长度分层，并非保护检查标签。这些样本沿用原 Diff 标签。原始倍率、约束损失和分类指标分别报告，检测收益由完整 Valid 分类指标判断。

新模型完整训练 wall time 57.88 分钟；55 项不同的相关单元测试通过，另有重复复查；真实 RTX4090 smoke 验证初始化、梯度、Padding、跨行 Token、恢复和源码单函数推理。未新增参数；最终 Python、NumPy、CPU/CUDA RNG 与历史基线逐项一致。

新方法完整 Valid P-C 未超过原 Context + Diff，按负结果停止；不搜索参数、不追加模块。
