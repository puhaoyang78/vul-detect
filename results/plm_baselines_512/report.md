# CodeBERT / CodeT5 三数据集、三方法、三种子对照

新增54组全部完成16 Epoch。复用现有数据、训练与评价入口；UniXcoder的27组正式结果仅作历史对照。原始源码、划分、标签及历史权重未改动。种子42、1234、123456；512 Token、Batch8、AdamW lr=2e-5。Context-only与RGCL仅相差0.1倍原始Token加权Diff区域损失，K=5。PrimeVul按完整Valid P-C选模，其他数据集按完整Valid MCC选模；阈值严格>0.5，Test不参与选模或调参。

CodeBERT使用CLS与原RoBERTa分类头。CodeT5使用[官方缺陷检测读出](https://github.com/salesforce/CodeT5/blob/main/CodeT5/models.py)：同函数右移解码器、末尾EOS表示、双类别线性头；Context-only/RGCL使用同一次前向的解码器Token表示进行原有物理行聚合。不计算生成损失，不增加编码次数，不在推理时读取Diff或修复版本。

全部新增组合的成员、16轮记录、优化步数、Valid选模、checkpoint与Valid/Test逐样本概率均经共享report入口复核。逐种子结果和命令见[CodeBERT报告](codebert/report.md)、[CodeT5报告](codet5/report.md)、commands.txt和各组config.json。下表为三种子均值±样本标准差；PR-AUC沿用average precision定义。
