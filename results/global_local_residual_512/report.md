## 结果解释

零初始化局部头、直接加法解决了首步局部头梯度被零融合系数阻断的问题。真实 GPU smoke 的初始化输出和原参数逐位一致，新增初始化不改变 CPU RNG 或采样；两次原优化器更新后局部参数、残差和预测概率都发生变化。局部残差单独反传也能更新编码器。106 项相关单元测试通过；覆盖稳定 LSE、Padding、跨行 Token 质量、checkpoint 恢复、原版本读取和单源码推理。完整训练三组首批损失相同，末态 CPU/CUDA RNG 一致，Mean/LSE 参数预算相同。

所选模型中局部分支已真实参与预测：Mean/LSE 分别改变 22/30 个 Valid 函数类别；同权重 global-only 消融的新增/丢失正确对分别为 3/4、6/1。LSE 的这 5 对净收益是局部残差的实际作用，但联合训练模型的 global-only 只有 80/562 对正确，融合后为 85/562，仍少于匹配独立基线的 100/562。不能把这两种比较混为一谈。

LSE 在固定 Test 上局部项改变 22 个函数类别，新增/丢失正确对 4/2；Mean 改变 39 个，新增/丢失 4/6。最终 Test LSE 71/564、Mean 67/564，均低于基线 77/564。LSE 相对独立基线新增 32 对、丢失 38 对。它的修复侧 FPR 从 55.14% 降至 42.20%，同时 Recall 从 63.83% 降至 49.82%；AUC/MCC 也下降，不能把减少判正解释为总体检测改善。

局部残差与全局 Logit 的 Valid 相关系数为 Mean -0.8733、LSE -0.8514；局部单支 AUC 为 0.4225/0.4304。LSE 局部项平均缩小配对 Logit 差 0.11234，仅纠正 1 对排序、破坏 3 对；Mean 缩小 0.13651，纠正 0、破坏 3 对。两者都降低同权重 Valid 的函数平均 BCE，但没有超过匹配基线的 P-C/AUC/MCC。结合下述源码案例，这些现象更支持置信度补偿和决策边界移动，尚未显示稳定的局部安全/漏洞互补信息。联合残差没有独立校准，局部单支 AUC 低不等于编码器完全没有信息。

LSE 聚合确实生效：同一头的 LSE margin 减行均值 margin，在 Valid 的均值为 -0.02924、标准差 0.04017；局部平均绝对残差为 0.28995。这次失败不能再归因于融合系数近零。Mean 与 LSE 只有聚合不同，LSE 的 Valid P-C 比 Mean 低 1.60 pp，固定 Test 高 0.71 pp，但两者都没有超过匹配基线；没有证据支持 LSE 的稳定优势。

修复类型也未形成总体改善：Mean 在 163 对纯新增修复上的 Valid P-C 为 25.77%，高于基线 22.70%，但在 396 对替换修复上由 15.91% 降至 13.13%；LSE 纯新增为 22.70%，替换为 12.12%。相同可见输入的 164 对仍然全部无法获得 P-C；可见差异 398 对上基线/Mean/LSE 分别为 25.13%/23.62%/21.36%。所有成员保留在完整指标中，没有按子集选择方法。

## 范围与结论

训练循环耗时 baseline/Mean/LSE 为 49.62/50.48/45.38 分钟，不含初始化、Tokenization、验证和离线诊断。LSE 原首次尝试因另一常驻 GPU 模型占用而在第一个优化步之前 OOM；用户释放显存后，通过正式 --resume 从 step 0 恢复。没有减小 Batch/输入、改变精度或训练步数，首批损失与末态 RNG 核对通过。等待资源的时间不计为训练耗时。

本轮停止。修正后的轻量双分支能够改变预测，并有少量同权重消融收益，但完整 Valid 和固定 Test 均没有超过匹配 Context + Diff；尚不足以保留为论文主要方法。未触发预先固定的第二种子条件，因此没有多种子稳定性结论，也没有追加温度、Top-K、融合方式、辅助损失或结构搜索。代码保留为可复现的实验对照，历史最佳权重未覆盖。
